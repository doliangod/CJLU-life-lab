# 大学四年人生实验室 · 教师使用说明

版本：1.1.0。以中国计量大学计量测试与仪器学院、测控技术与仪器专业为课堂示例。
共33页、7处互动，建议授课22分钟。所有经历、项目成果和省赛金奖均为课堂情境推演。

## 打开课件

### 已有学校网页链接

使用Chrome或Edge打开学校提供的HTTPS链接，按F全屏即可。老师无需安装Node.js。

### 使用本地教学发布包

1. 完整解压教学发布包。不要直接双击site目录里的index.html。
2. 课前在电脑上安装Node.js 24或更高版本，并确认Chrome或Edge可用。
3. Windows双击“启动课件-Windows.cmd”；macOS双击“启动课件-macOS.command”。也可以在发布包目录执行 `node serve.mjs`。
4. 浏览器打开 `http://127.0.0.1:4173`。授课期间保留启动窗口。
5. 此发布包已包含编译后的网页，不需要npm install；安装好Node.js以后可断网授课。

若提示端口4173被占用，请关闭之前的课件启动窗口后重试。不要重复启动多个服务。
macOS若限制.command执行，可在终端进入发布包目录，执行 `node serve.mjs`。

## 开始与继续授课

- 已完成的选择、未选满的多选草稿、当前页面和已用时间自动保存在当前浏览器。
- 刷新或重新打开相同网址时，可选择“继续上次课程”。计时器恢复后先暂停，按T继续。
- 选择“从头开始”或按R后，会再次要求确认。默认焦点停在“取消”，误按Enter不会清空课程。
- 不同电脑、浏览器、浏览器用户和网址的进度不共享；清除浏览器数据会清除本机存档。建议每堂课只开一个授课标签页。
- 本地恢复不需要网络或后台。浏览器禁止存储时仍能上课，但刷新后无法恢复，页脚会提示。

## 常用操作

| 操作 | 按键 / 按钮 |
|---|---|
| 翻页 | 空格 / →，←回看 |
| 选择选项 | 数字1—6，或鼠标点击 |
| 确认多选 | 选满指定数量后按Enter或点击确认 |
| 修改答案 | 点击“重新选择”；其他题答案保留 |
| 讲师提示 | P或底部麦克风按钮；提示显示在当前屏幕上 |
| 计时 | T显示计时器，显示时开始 / 暂停；计时器的×仅隐藏，计时继续 |
| 全屏 | F |
| 帮助 | H；Esc关闭 |
| 重新开始 | R或底部重置按钮，随后确认 |

鼠标操作后可直接继续使用方向键。打开帮助、恢复或重置弹窗时，课程操作被隔离。

## 课程表达

- 时间主线为2026入学、2027—2028项目体验、2029秋招、2030届毕业。结尾重新回到2026，落实未来30天行动。
- “1460天”与页面剩余天数是教学中的约数，用于说明成长阶段，不是精确日历倒计时。
- 成长面板只记录“本次涉及的能力关键词”“完成的互动”和两段课堂体验，不作能力测评。
- “本次课堂的问题解决路线”展示本次选择；“教师参考方法”是额外讨论素材，不会自动写入个人简历。
- 换题选项代表提出评估方向；后续统一观察原项目团队成果，并明确这一课堂设定。

## PDF的用途与示例路线

PDF是33页静态预览，不能点击、改选或恢复进度。互动页展示作答前状态，后续经历使用下面的固定示例路线：

校园参与：加入学生组织；角色：活动策划；优先：活动内容、现场安全、互动体验；故障处理：调整流程。
专业兴趣：想真正试着做点东西；初始任务：查阅资料、设计测试方案；解决方法：重新实验、请教老师、与队友讨论。

其他选择组合请在网页版查看。PDF不包含全部结果分支。

## 给信息化部门的部署说明

将“网页部署包”解压后的index.html与assets文件夹放到静态网站目录，提供HTTPS网址即可。
也可部署教学发布包中的site目录。支持域名根目录或子目录；无数据库、登录、扫码或投票服务。
不要把serve.mjs作为公网服务使用，它只监听本机地址，供教师本地授课。
